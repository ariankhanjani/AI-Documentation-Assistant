# E-commerce Data Analysis & Dashboard

An end-to-end **E-commerce Data Analysis** project covering data exploration, statistical hypothesis testing, KPI analysis, and interactive dashboard development.

## 📊 Project Overview

The project analyzes e-commerce sales and customer data to identify key business patterns, trends, and performance indicators.

### Workflow

**Python → Excel → Power BI**

* **Python:** Data cleaning, EDA, visualization, and statistical hypothesis testing
* **Excel:** Pivot Tables and KPI analysis
* **Power BI:** Interactive dashboard and data visualization

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* SciPy
* Excel
* Power BI

## 🔍 Analysis

### Exploratory Data Analysis

Performed EDA to investigate:

* Outlier detection and data cleaning
* Check Data types
* Sales and revenue distributions
* Category performance
* Discounts and order patterns
* Monthly trends
* Outlier detection and data cleaning

### Statistical Analysis

Conducted statistical hypothesis tests to validate relationships and differences observed in the data.

### Excel Analysis

Created:

* Pivot Tables
* Business KPIs
* Monthly and category-level performance analysis

### Power BI Dashboard

Built an interactive dashboard to monitor key business metrics and visualize sales performance and trends.
